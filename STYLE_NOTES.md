# Style notes

The application theme is defined in `app/globals.css` and mapped to Tailwind v4 tokens.

- Ivory `#FBF6EE`, cream `#F3E9DA`, maroon `#7A1424`, deep maroon `#4A0B15`.
- Gold `#C9A24B`, soft gold `#E7D3A0`, ink `#1A0D10`, muted `#6B5A5A`.
- Semantic RSVP colors: readable green, red, amber, and gray pairs with tinted backgrounds.
- Fonts: Italiana for large headings, Cormorant Garamond for accents, Outfit for interface text.
- Shared UI: Button, Input, Badge, Modal, Tabs, Card, Select, Textarea, Skeleton, Toast.
- Invitation artwork under `components/templates/` intentionally keeps each template's own palette and host-selected colors.
