Wedding Invitation Website

Open index.html in any modern browser.

Included:
- Responsive desktop + mobile design
- Uploaded wedding illustrations
- Countdown timer
- RSVP form (demo: saves to browser localStorage)
- Location section
- Embedded OpenStreetMap
- Google Maps button

To publish:
Upload the entire folder to Netlify, GitHub Pages, Vercel, or your normal web hosting.

To make RSVP submissions actually reach you, connect the form to Formspree, Netlify Forms, Firebase, Supabase, or your own backend.
